■ 必要な環境
Windows、Git、Python 3、Node.js、Premiere Pro 2026（標準トランジションは26.0以降）。
確認済み: Node.js v24.14.1 / Python 3.14.3 / Git 2.55.0.windows.3。
PowerShellで python / node / git が使える状態にします。
ブラウザのWebフォント初回取得にはインターネット接続が必要です。
Premiereで使うフォントはPC側にもインストールします。フォント本体は同梱していません。
  Noto Sans JP Black / Bold（NotoSansJP-Black / NotoSansJP-Bold）
  Noto Serif JP Black（NotoSerifJP-Black）
  游ゴシック Bold（YuGothic-Bold）、游明朝 Demibold（YuMincho-Demibold）
  Segoe UI Symbol（SegoeUISymbol。星の✦／✧に使用）
括弧内はXMLへ渡すPostScript名です。表示用のフォント名から推測しないでください。

■ 次のPCで開く
1. bundleを置いたフォルダーでPowerShellを開き、次を実行します。

   git clone --branch effects/premiere-editable .\telop-studio-effects-20261023.bundle telop-studio
   cd telop-studio
   git remote set-url origin https://github.com/rharada525-stack/telop-studio.git
   git status --short --branch
   git log -1 --oneline
   node --test tests/*.test.mjs

   引き継ぎ時点は127テスト成功。既存の作業フォルダーを上書きしないでください。
   ZIPを使う場合は新しいフォルダーへ展開します。Git履歴の復元にはbundleを使います。

2. リポジトリ直下で起動します。

   .\admin\effects-lab\Start-Lab.ps1

   http://127.0.0.1:8767/admin/effects-lab/ をブラウザで開きます。
   スクリプトはPythonのHTTPサーバーを127.0.0.1だけに起動します。
   PowerShellは開いたまま使用し、終了はCtrl+C。
   ポートが使用中なら -Port 8768 などを付け、表示されたURLを開きます。

3. 「文字に光が走る」「光と宝石のフィナーレ」を選び、横長・下配置、
   デザイン切替、再生・逆シークを確認します。保存JSONがあれば読み込みます。
   「標準指定」のJSONも「JSONを読み込む」から復元できます。

4. XMLをPremiereの新しい検証プロジェクトへ読み込みます。
   表面光付きは「本文を編集_…」シーケンス内の文字を1か所で変更すると、
   原色と光沢の両層へ反映されます。変更・取り消しを確認し、元の作品は保護します。
   標準ネオン／ライトスイープは admin/effects-lab/samples/premiere-native-light.prproj
   を開きます。これはPremiere本体で保存したサンプルです。

■ 現在の到達点と進め方
ローカル管理者ラボに15種類の動き、22種類のデザインがあります。
横長は基本下中央、傾き0度。動きとデザイン・書体を分けて選べます。
本文はPremiereで編集できるテキスト。MP4・字幕画像・MOGRTへ置き換えません。
キラキラは別トラックの編集可能な星文字、表面光は本文1個を共有したネストです。
今後は用途別の見た目やリッチなデザインを追加し、ユーザーが良い案を最終標準に選びます。
「この動きの標準にする」はこのPCのラボ内の指定で、公開版は変わりません。
ラボはadmin/effects-lab/にあり、GitHub Pagesの公開対象telop-studio/の外です。

■ 既知の制限
PremiereのSource Text形式は公開仕様ではないため、版が変われば再確認が必要です。
全書体・縦横・全フレームの完全一致を実機確認したわけではありません。
文章の幅を大きく変更すると、星の位置や光沢帯のCrop調整が必要な場合があります。
Premiere標準のネオンワイプ／ライトスイープはFCP7 XMLで保持できないため、
専用の本体保存.prprojで渡します。検証範囲・未対応表現は../../README.mdを参照。
