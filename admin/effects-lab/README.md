# 演出ラボ（ローカル管理者用）

PowerShellで `./admin/effects-lab/Start-Lab.ps1` を実行し、表示されたURLを開きます。Python 3が必要です。
標準URL: `http://127.0.0.1:8767/admin/effects-lab/`。終了はサーバーの画面で Ctrl+C。

- 左から演出を選び、再生・0.25/0.5倍速・1コマ送りで登場と退場を確認。
- 縦横、デザインセット、演出の文字、通常字幕、位置、画面効果を切り替えられます。
- 「元と比較」で、同じ時刻・背景の本体版と試作を並べます。音は試作側だけです。
- パーツを選び、文字サイズ・動き・傾きやスタイルJSONを調整。縦と横の調整は別々に保持します。
- 「試作を保存」はラボ専用のブラウザ保存。編集中の試作も自動で復元します。背景の画像・動画は保存しません。
- 保存済みの試作を読み込んで保存すると上書き。「別の試作として保存」で調整中の内容を別枠に残せます。「新しい試作」は初期状態から開始。
- 「JSONに保存」でバックアップ・受け渡し。「JSONを読み込む」で続きから再開。PNGは現在のフレーム（ガイドなし）。
- 動画の背景は音声を出さずに再生します。動画の開始位置も指定できます。低速時の効果音はタイミングだけ同期し、音程は変えません。

## 本体との関係

`telop-studio/js/render.js`、`telop.js`、`timeline.js`、`sets.js`、`styles.json`、`sfx/` を直接使います。
本体の演出一覧に種類を追加すればラボにも出ます。新しい文字スタイルや動きの試作は、ここで比較してから本体へ反映します。
見出しは全体・ラベル・本文を別々に選べます。画面効果の動き自体は本体のRendererで管理し、ラボでは組み合わせを試します。

ラボは公開対象の `telop-studio/` の**外**にあり、GitHub Pagesの成果物に入りません。
編集画面のリンク、プロジェクト保存、字幕の標準設定、AIモデルにも触れません。
ローカルホスト以外では起動しない補助チェックもありますが、認証の代わりではありません。
リポジトリ自体の公開範囲は変えません。将来オンラインで管理する場合は、別途認証付きの配置が必要です。

## Premiere用テキストXML（読み込みテスト）

以前の直接生成 `.prproj` は、ユーザーのPremiereで「プロジェクトが壊れているため開けません」となりました。
この出力は撤去し、XMLでの読み込み検証に切り替えています。

ページ末尾の「この文字をXMLに保存」で選択中の演出の文章と表示時間を書き出します。
「文字3個のXMLを保存」は、見本文字を0.5〜3.5秒・4.5〜7.5秒・8.5〜11.5秒に並べます。
30fpsのFCP 7 XML（xmeml version 5）のText generatorです。字幕の画像・動画、MOGRT、外部素材は含みません。
白文字・中央配置・Noto Sans JPの太字という共通設定で、文章・改行・表示時間の取り込みだけを検証します。
**ラボのデザイン（色・フチ・傾き・影・動き・複合パーツ）や通常字幕・背景・効果音は含みません。**

Premiereで新規の空プロジェクトを作り、「ファイル → 読み込み」でXMLを取り込みます。
シーケンスに文字が表示され、文章を書き換えられるか、時間が合うか、保存と再読み込みができるかを確認します。
読み込みレポートや警告が出た場合は内容も確認してください。
現行Premiereでの読み込み・ネイティブ文字編集は未確認です。構文チェックだけで対応済みとは扱いません。
「強調・白フチ」「ツッコミ・赤」「見出し・イエロー」はブラウザでのデザイン試作として残しています。
公開版のPremiere ZIP出力は従来のままです。

形式の根拠:
- [AppleのText generator字幕例](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/FinalCutPro_XML/Applications/Applications.html#//apple_ref/doc/uid/TP30001156-CH6-SW2)
- [Adobeの旧CS6資料](https://helpx.adobe.com/pdf/cs6/premiere_pro_reference.pdf) はText generatorからタイトルへの変換を記載していますが、現行版の保証にはなりません。
