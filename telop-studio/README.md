# テロップスタジオ

話している動画を入れると、**無言部分の自動カット → 文字起こし → テレビ風テロップ＋効果音 → MP4 書き出し**
までをブラウザだけで行うツールです。縦 9:16（ショート）と横 16:9（YouTube など）の両方に書き出せます。

- 無料。Claude もアカウントも不要
- 動画と音声は外部に送られず、使う人のパソコンの中だけで処理される
- 必要なもの: パソコンの **Chrome または Edge**（スマホ・Safari は非対応）

## 使い方（生徒さん向け）

1. **素材を選ぶ**: 話している動画をドロップする
   - **複数の動画をまとめて入れると、1本につながる**（ファイル名順に並ぶ。↑↓で入れ替え、✕で外せる）
   - 「出力の形」で **縦 9:16** か **横 16:9** を選ぶ（あとから切り替えてもテロップの配置は自動で直る）
   - 「画面の合わせ方」は「おまかせ」がおすすめ。素材と出力の縦横が同じなら画面いっぱいに切り抜き、
     違えば全体を表示してぼかし背景を付ける（縦撮りと横撮りが混ざっていても大丈夫）
2. **解析する**: 無言部分のカットと文字起こしを自動で行う
   - 初回だけ AI モデルをダウンロードする（標準で約550MB。2回目以降は不要。学校の回線なら事前に済ませておくと安心）
   - 「間の詰め具合」スライダーで、カットのテンポをあとから調整できる
   - 複数人の会話なら「話者も自動で分ける」にチェック（同時に判別できるのは3人まで）。
     声が似ている人どうしや、声が重なった部分は間違えることがあるので、表の「話者」欄で直す。
     文字起こしの後からでも「話者だけ分け直す」で判別できる
3. **テロップを直す**
   - まず「✨ おまかせ編集」を押すと、字幕の言葉から演出を自動で付ける
     （つかみ・見出し「その1」・ツッコミ・オチ・締め・ズーム・暗転・数字や強い言葉の強調色・「えーと」だけの行のカット）。
     強さは 控えめ／標準／派手。「元に戻す」で押す前に戻せる。手で設定した行は変えない。
     ※キーワードのルールで判断している（内容をAIが理解しているわけではない）ので、たたき台として使い、表で整える
   - 字幕の文字は表で直接直せる。`{ }` で囲むと黄色で強調される
   - 「演出」を選ぶと、テレビ風の演出テロップと効果音が付く
     （煽り・キーワード・ツッコミ・見出し・オチ・締め）
   - 「演出の文字」を空にすると、その字幕自体が演出テロップになる
   - 見出しは「その1/氷は先に揺らす」のように `/` で区切る
   - 言い間違いや「えーと」の行は「カット」にチェックすると、映像ごと消える
   - 時間をクリックするとその場所へ移動。スペースキーで再生・停止
   - 演出テロップの「位置」は おまかせ／左上／上／右上／真ん中／下 から選べる
     （横長では、おまかせでも人と重ならないよう見出しは左上、強調は下に出る）
   - 「画面効果」で ズーム・集中線・フラッシュ・モノクロ＋暗く・周りを暗く・モノクロ・揺れ を付けられる
     （演出テロップのない行にも付けられる）
4. **字幕のデザイン**（クリックで開く）
   - Premiere のエッセンシャルグラフィックスと同じ考え方で、フォント・サイズ・字間・行間・塗り・
     境界線・シャドウ（不透明度・角度・距離・ブラー）・背景（座布団）・位置X/Y を数値で指定できる
   - 境界線は「＋ 境界線を追加」で何本でも重ねられる（上が内側。↑↓で順番を入れ替え、✕で削除）
   - 文字の色と各境界線にはグラデーションを付けられる（始まり→中間→終わりの色、角度 0°=上→下 / 90°=左→右）
   - アニメーションは標準で「なし」。フェード／1文字ずつ表示／1文字ずつポップ に変えられる
   - 「デザインを保存」で JSON ファイルになる。マニュアルの指定どおりに作ったファイルを配れば、
     生徒さんは「デザインを読み込む」だけで同じデザインになる。「新しい作業の標準にする」で毎回の初期値にできる
   - 「PCのフォント」を押すと、パソコンに入っているフォントも候補に出る
   - **話者ごとに別のデザインにできる**。パネル上の話者タブで切り替え、名前も付けられる（例：司会・ゲスト）。
     位置X/Yも話者ごとなので、左の人の字幕は左、右の人の字幕は右、のようにもできる。
     「全員分を保存」でまとめて1つのファイルにできる
5. **音のバランス**: 声の大きさは自動でそろう。声・効果音それぞれ音量スライダーで調整できる
6. **書き出す**: 「MP4 を書き出す」でダウンロードされる
   - Premiere で仕上げたい場合は「字幕ファイル（SRT）」も出せる
7. **Premiere Pro で仕上げる**（任意）: 「Premiere 用に書き出す（ZIP）」
   - カット済みの素材・テロップ（透過PNG）・集中線・暗転・フラッシュ・効果音（音量込み）・ズームを並べた
     編集データ（FCP7 XML）を、画像・効果音・字幕SRT・手順書と一緒に ZIP にする
   - 「元の動画が入っているフォルダ」にエクスプローラーのアドレスを貼っておくと、Premiere で開いたときに
     そのまま素材がつながる（空でも、開くときに1つ選べば残りは自動で見つかる）
   - ZIP は元の動画と同じフォルダに展開し、中の XML を［ファイル］→［読み込み］で開く
   - テロップのアニメーション・モノクロ・揺れ・ぼかし背景は画像では再現できないので入らない

作業内容はブラウザに自動保存されます。同じ動画（複数なら同じ組み合わせ・同じ順番）を入れ直すと続きから再開できます。
素材を追加・削除・並べ替えると、文字起こしはやり直しになります（確認が出ます）。
「作業を保存」で JSON に書き出せば、別のパソコンでも続きができます。

## 配布のしかた（先生向け）

このフォルダは**Web サーバーから開く必要があります**（`index.html` をダブルクリックしただけでは動きません）。

- **おすすめ: GitHub Pages で公開する**（無料）
  → このフォルダを GitHub のリポジトリに置いて Pages を有効にすると、生徒さんは URL を開くだけで使える
- 手元で試すだけなら、このフォルダで次のコマンドを実行して `http://localhost:8765` を開く

```bash
python -m http.server 8765
```

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` / `css/app.css` | 画面 |
| `js/app.js` | 画面の操作・再生・保存 |
| `js/timeline.js` | 無音検出・字幕の分割と改行・カット後の時間計算・演出の割り当て |
| `js/whisper-worker.js` | 文字起こし（Whisper をブラウザ内で実行） |
| `js/telop.js` | テロップ描画エンジン（多重フチ・グラデ・座布団・アニメ） |
| `js/render.js` | 1コマの合成（動画＋テロップ） |
| `js/decode.js` / `js/export.js` | 動画のデコードと MP4 書き出し |
| `styles.json` | テロップのデザイン（Python 版と共通） |
| `sfx/*.wav` | 効果音（コードで合成したもの・著作権フリー） |

## わかっている制限

- 文字起こしは、話し方・録音状態によって誤字が出る（「標準」→「高精度」で改善する）
- 言い間違いなどの自動カットは「無言部分」だけ。言葉単位のカットは表の「カット」で行う
- iPhone の HEVC（H.265）動画は、パソコンによっては読めないことがある
  （そのときは H.264 の MP4 に変換してから使う）
- MP4 / MOV は数GBの素材でも扱える（必要な部分だけ少しずつ読むため、メモリをほとんど使わない）
- MP4 / MOV 以外（WebM など）は 800MB までで、書き出し中にタブを開いたままにする必要がある。複数素材をつなぐときは全部 MP4 / MOV にする
- 合計 20 分を超える素材は警告が出る（動くが、文字起こしに時間がかかる）
