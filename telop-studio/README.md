# テロップスタジオ

話している動画を入れると、**無言部分の自動カット → 文字起こし → テレビ風テロップ＋効果音 → MP4 書き出し**
までをブラウザだけで行うツールです。縦 9:16（ショート）と横 16:9（YouTube など）の両方に書き出せます。

- 無料。Claude もアカウントも不要
- 動画と音声は外部に送られず、使う人のパソコンの中だけで処理される
- 必要なもの: パソコンの **Chrome または Edge**（スマホ・Safari は非対応）

## 使い方（生徒さん向け）

1. **素材を選ぶ**: 話している動画をドロップする
   - **複数の動画をまとめて入れると、1本につながる**（ファイル名順に並ぶ。↑↓で入れ替え、✕で外せる）
   - 「出力の形」で **縦 9:16** か **横 16:9** を選ぶ（あとから切り替えてもテロップの配置は自動で直る）
   - 「テロップのデザインセット」で雰囲気をまとめて切り替えられる
     - 標準（テレビ風）／エンタメ切り抜き風（画面いっぱいの縦書き・黒枠の白箱・筆文字）／
       ビジネス講義風（下の黒帯に白い明朝の字幕・要点は大きな2色の強調・見出しは左上のコーナー名）
     - 字幕のデザインと、演出テロップの見た目（キーワード・煽り・オチなど）が一緒に変わる。おまかせ編集の向きも合わせて変わる
   - 「画面の合わせ方」は「おまかせ」がおすすめ。素材と出力の縦横が同じなら画面いっぱいに切り抜き、
     違えば全体を表示してぼかし背景を付ける（縦撮りと横撮りが混ざっていても大丈夫）
2. **解析する**: 無言部分のカットと文字起こしを自動で行う
   - 標準は「高精度」（初回ダウンロード約1.5GB）。重い・解析に失敗する場合は「低スペックモード」（約200MB）を選ぶ（精度は下がる）。2回目以降のダウンロードは不要
   - 待ち時間が長い場合は「解析を中止」で止めて、モードを切り替えて解析し直せる。中止しても今ある字幕は残る
   - 「自動カットの種類」で「1人で話す（0.6秒以上の無言）」「会話・対談（1.0秒）」「バラエティ・間を残す（1.5秒）」を選べる。
     「カットする無言の長さ」スライダーで、あとから細かく調整できる
   - 小さな声も拾えるよう、平均の音量に加えて瞬間の音量も見る。文字起こし後は、言葉を話している所は切らない
   - 言い直し・同じ言い回しの繰り返し・「ちょっと待って」などの中断は、表に「言い直し?」などの印が付く（お知らせだけで、自動ではカットしない）。
     印にマウスを乗せると理由と残す方の文章が見え、印をクリックするとその行をカット／元に戻せる
   - 複数人の会話なら「話者も自動で分ける」にチェック（同時に判別できるのは3人まで）。
     声が似ている人どうしや、声が重なった部分は間違えることがあるので、表の「話者」欄で直す。
     文字起こしの後からでも「話者だけ分け直す」で判別できる
3. **テロップを直す**
   - まず「✨ おまかせ編集」を押すと、字幕の言葉から演出を自動で付ける
     （つかみ・見出し「その1」・ツッコミ・オチ・締め・ズーム・暗転・数字や強い言葉の強調色・「えーと」だけの行のカット）。
     強さは 控えめ／標準／派手。「元に戻す」で押す前に戻せる。手で設定した行は変えない。
   - 「字幕の大事な言葉を自動で強調色にする」（標準でオン）：数字＋単位、「実は」「一番」「裏ワザ」などの言葉、
     「」の中を強調色にする。表示のときだけ付くので、オフにすると元に戻る。自分で { } を付けた行はそのまま
   - 「向き」は ショート向け（テンポ重視：つかみ・数字のキーワード・頻繁なズーム・揺れ・集中線）と
     長尺向け（落ち着いて：話題の見出し・まとめ見出し・ズームは控えめ・数字は色だけ・暗転は控えめ）。
     出力の形に合わせて自動で切り替わる（縦→ショート、横→長尺）。手で選ぶとそのまま
   - 「えっと2つ目」「えーと、次に」のように、つなぎ言葉が前に付いた見出しも拾う（字幕の本文は変えない）
   - ほかに拾うもの：「次に／最後に」→ その2・その3、「さて／ところで」→ 話題の見出し（長尺）、
     「まとめると」→ まとめ（長尺）／オチ（ショート）、笑い声 →（笑）、問いかけ・「！」→ ズーム（ショート）
     ※キーワードのルールで判断している（内容をAIが理解しているわけではない）ので、たたき台として使い、表で整える
   - 字幕の文字は表で直接直せる。`{ }` で囲むと強調色、`[ ]` で囲むと2つ目の強調色になる
     （「強調部分の大きさ」を上げると、強調した部分だけ大きくなる）
   - 演出テロップの種類：キーワード・煽り・ツッコミ・見出し・オチ・締め に加えて、
     縦書き（大）・白箱（問いかけ・引用）・ビジネス強調（2色）・コーナー名（左上）・この後（右上）・
     手書き風・ホラー・注釈（※小さく）・名前テロップ・筆文字タイトル
   - 「演出」を選ぶと、テレビ風の演出テロップと効果音が付く
     （煽り・キーワード・ツッコミ・見出し・オチ・締め）
   - 「演出の文字」を空にすると、その字幕自体が演出テロップになる
   - 見出しは「その1/氷は先に揺らす」のように `/` で区切る
   - 言い間違いや「えーと」の行は「カット」にチェックすると、映像ごと消える
   - 時間をクリックするとその場所へ移動。スペースキーで再生・停止
   - 演出テロップの「位置」は おまかせ／左上／上／右上／真ん中／下 から選べる
     （横長では、おまかせでも人と重ならないよう見出しは左上、強調は下に出る）
   - 「画面効果」で ズーム・集中線・フラッシュ・モノクロ＋暗く・周りを暗く・モノクロ・揺れ を付けられる
     （演出テロップのない行にも付けられる）
4. **字幕のデザイン**（クリックで開く）
   - Premiere のエッセンシャルグラフィックスと同じ考え方で、フォント・サイズ・字間・行間・塗り・
     境界線・シャドウ（不透明度・角度・距離・ブラー）・背景（座布団）・位置X/Y を数値で指定できる
   - 境界線は「＋ 境界線を追加」で何本でも重ねられる（上が内側。↑↓で順番を入れ替え、✕で削除）
   - 文字の色と各境界線にはグラデーションを付けられる（始まり→中間→終わりの色、角度 0°=上→下 / 90°=左→右）
   - アニメーションは標準で「なし」。フェード／1文字ずつ表示／1文字ずつポップ に変えられる
   - 「デザインを保存」で JSON ファイルになる。マニュアルの指定どおりに作ったファイルを配れば、
     生徒さんは「デザインを読み込む」だけで同じデザインになる。「新しい作業の標準にする」で毎回の初期値にできる
   - 「PCのフォント」を押すと、パソコンに入っているフォントも候補に出る
   - **話者ごとに別のデザインにできる**。パネル上の話者タブで切り替え、名前も付けられる（例：司会・ゲスト）。
     位置X/Yも話者ごとなので、左の人の字幕は左、右の人の字幕は右、のようにもできる。
     「全員分を保存」でまとめて1つのファイルにできる
5. **音のバランス**: 声の大きさは自動でそろう。声・効果音それぞれ音量スライダーで調整できる
6. **書き出す**: 「MP4 を書き出す」でダウンロードされる
   - Premiere で仕上げたい場合は「字幕ファイル（SRT）」も出せる。締めなどの演出に置き換えた字幕も含む（カットした行は除く）
7. **Premiere Pro で仕上げる**（任意）: 「Premiere 用に書き出す（ZIP）」
   - カット済みの素材・テロップ（透過PNG）・集中線・暗転・フラッシュ・効果音（音量込み）・ズームを並べた
     編集データ（FCP7 XML）を、画像・効果音・字幕SRT・手順書と一緒に ZIP にする
   - 「元の動画が入っているフォルダ」にエクスプローラーのアドレスを貼っておくと、Premiere で開いたときに
     そのまま素材がつながる（空でも、開くときに1つ選べば残りは自動で見つかる）
   - ZIP は元の動画と同じフォルダに展開し、中の XML を［ファイル］→［読み込み］で開く
   - テロップのアニメーション・モノクロ・揺れ・ぼかし背景は画像では再現できないので入らない

作業内容は、動画ごとの「プロジェクト1・2…」にブラウザ内で自動保存されます。

- 同じ動画（複数なら同じ組み合わせ・同じ順番）を入れ直すと、最後に使ったプロジェクトを開きます。
- 「プロジェクトを選ぶ」→「続きから開く」で、ほかのプロジェクトに戻れます。「プロジェクト名」で名前も変えられます。
- 「新しく始める」は、今の編集を残したまま、字幕・演出・設定が初期状態の新しいプロジェクトを作ります。
- 「プロジェクトを複製」で、字幕やデザインを引き継いで別の編集を作れます。
- 以前の1件だけの自動保存は「プロジェクト1」として引き継ぎます。
- 以前の「セーブデータ1・2…」は「プロジェクト1・2…」に表示名を変更します。自分で付けた名前や編集内容は引き継ぎます。
- 素材を追加・削除・並べ替えると、文字起こしはやり直しになります（確認が出ます）。変更前の組み合わせのプロジェクトは残ります。
- 動画本体は保存しません。ブラウザやPCを変える場合は「JSONに保存」でバックアップし、同じ動画と一緒に用意してください。
- 「JSONを開く」は既存プロジェクトを上書きせず、別プロジェクトとして開きます。動画の名前・サイズ・並び順が一致する素材が必要です。
- ブラウザの容量が足りず保存できない場合は画面に表示します。その場合も「JSONに保存」で編集中のデータを書き出せます。

### 編集の取り消し・字幕の初期化

「テロップを直す」の上に「元に戻す」「やり直す」「字幕をすべて初期化」があります。

- 文章の修正、デザイン、演出、画面効果、カット、おまかせ編集などを、最大50操作まで取り消し・やり直しできます。
- Ctrl+Z（Macは⌘Z）で取り消し、Ctrl+Shift+Z／Ctrl+Y（Macは⌘⇧Z）でやり直せます。文字入力中は、その入力欄の通常の取り消しを使います。
- 「字幕をすべて初期化」は、修正した文章・時間・話者・追加した字幕を残し、全員のデザインを標準に戻して、演出・画面効果・カット指定を解除します。タイトル帯・画面サイズ・音量などは残ります。
- 初期化やおまかせ編集も1操作として取り消せます。
- 履歴は編集中のプロジェクト内で保持します。別のプロジェクトや素材への切り替え、ページの再読み込みで履歴はリセットされます。編集結果は引き続き自動保存されます。

### ダウンロード済みAIモデルの削除

モデルは、サイトとブラウザごとの Cache Storage（`transformers-cache`）に保存されます。
「自動カット＋文字起こし」内の「ダウンロード済みAIモデルの管理」を開くと、保存状況を確認できます。
「このツールのAIモデルを削除」は、文字起こし・話者判別のモデル関連ファイルだけを削除します。
プロジェクト・字幕デザイン・元動画は残ります。次の解析時に必要なモデルを再ダウンロードします。
解析中はプロジェクトの切り替え・モデル削除を行えません。必要なら先に「解析を中止」を押してください。

ブラウザの「サイトデータをすべて削除」はプロジェクトも消すため、モデルだけ消したい場合は上のボタンを使ってください。

## 配布のしかた（先生向け）

このフォルダは**Web サーバーから開く必要があります**（`index.html` をダブルクリックしただけでは動きません）。

- **おすすめ: GitHub Pages で公開する**（無料）
  → このフォルダを GitHub のリポジトリに置いて Pages を有効にすると、生徒さんは URL を開くだけで使える
- 手元で試すだけなら、このフォルダで次のコマンドを実行して `http://localhost:8765` を開く

```bash
python -m http.server 8765
```

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` / `css/app.css` | 画面 |
| `js/app.js` | 画面の操作・再生・保存 |
| `js/timeline.js` | 無音検出・字幕の分割と改行・カット後の時間計算・演出の割り当て |
| `js/whisper-worker.js` | 文字起こし（Whisper をブラウザ内で実行） |
| `js/telop.js` | テロップ描画エンジン（多重フチ・グラデ・座布団・アニメ） |
| `js/render.js` | 1コマの合成（動画＋テロップ） |
| `js/decode.js` / `js/export.js` | 動画のデコードと MP4 書き出し |
| `styles.json` | テロップのデザイン（Python 版と共通） |
| `sfx/*.wav` | 効果音（コードで合成したもの・著作権フリー） |

## わかっている制限

- 文字起こしは、話し方・録音状態によって誤字が出る。標準の「高精度」で解析し、字幕を確認して直す
- 自動カットは「無言部分」だけ。言い直しは印でお知らせするだけなので、カットするかは表の「カット」か印のクリックで決める
- iPhone の HEVC（H.265）動画は、パソコンによっては読めないことがある
  （そのときは H.264 の MP4 に変換してから使う）
- MP4 / MOV は数GBの素材でも扱える（必要な部分だけ少しずつ読むため、メモリをほとんど使わない）
- MP4 / MOV 以外（WebM など）は 800MB までで、書き出し中にタブを開いたままにする必要がある。複数素材をつなぐときは全部 MP4 / MOV にする
- 合計 20 分を超える素材は警告が出る（動くが、文字起こしに時間がかかる）
